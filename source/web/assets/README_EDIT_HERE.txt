MRX NEXUS — EDIT ONLY THIS ASSETS FOLDER

You do not need to edit index.html, style.css or script.js.

1. settings/config.js  = server name, logo, links, colors, video, music and tips
2. settings/rules.js   = server rules
3. settings/team.js    = staff members
4. settings/gallery.js = gallery list
5. settings/events.js  = event list
6. gallery/            = your server screenshots
7. events/             = your event posters
8. avatars/            = staff profile images
9. music/              = up to 3 songs and covers
10. logo.png           = server logo
11. background.mp4     = loading background video

Always keep file names and paths consistent with the entries inside assets/settings.
