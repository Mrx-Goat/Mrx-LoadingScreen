EVENT SETUP

1. Put your event poster images in this folder.
2. Open: web/assets/settings/events.js
3. Edit status, title, date, time, location, reward, image and description.
4. The image field is optional. Remove the image line to display a text-only card.

Example image path:
assets/events/car-show.webp

Recommended poster size: 1200x675 or 1600x900.
