GALLERY SETUP

1. Delete the sample gallery images when ready.
2. Add your own PNG, JPG, JPEG or WEBP screenshots here.
3. Open: web/assets/settings/gallery.js
4. Change image, title and caption for each entry.
5. You may add or remove gallery entries.

Example image path:
assets/gallery/police-event.webp

Recommended size: 1600x900 or 1920x1080.
Use compressed WEBP/JPG files for faster loading.
