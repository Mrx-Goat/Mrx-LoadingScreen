EDITABLE DATA FILES

config.js  = identity, theme, background, music and tips
rules.js   = rules
team.js    = staff members
gallery.js = gallery entries
events.js  = events

Edit only values. Keep brackets, quotes and commas valid.
Do not rename window.MRX_CONFIG, window.MRX_RULES, window.MRX_TEAM,
window.MRX_GALLERY or window.MRX_EVENTS.
